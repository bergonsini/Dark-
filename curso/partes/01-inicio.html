Boas-vindas!

Este é um curso prático. Ao final, você vai ter um estúdio de animação (no celular ou no computador) que transforma um pedido em português, como "faz um vídeo explicando por que o céu é azul", em um vídeo MP4 vertical: animado, narrado, com legenda sincronizada, música e efeitos, pronto para postar.

Você não precisa saber desenhar, programar ou editar. Quem escreve o roteiro, o código da animação e os scripts é a IA (Claude). O seu papel é o de diretor: escolher a ideia, aprovar o rascunho e dizer o que mudar.

Dá pra fazer TUDO pelo celular

Você não precisa de computador. Todo o método desta apostila funciona direto do app do Claude no celular: o Claude trabalha num computador na nuvem, instala tudo, anima, narra e renderiza, e o vídeo pronto chega na conversa para você baixar e postar.

O autor deste método produz os vídeos 100% pelo celular. Os caminhos "pelo celular" e "pelo computador" estão lado a lado no Módulo 2: escolha o seu.

Como usar esta apostila

  • Módulos 1 a 5 são a base: faça na ordem, uma única vez. Depois que o estúdio está montado, você não volta mais neles.
  • Módulo 6 tem um capítulo por formato de vídeo. Escolha um ou dois para começar; não precisa fazer todos.
  • As caixas roxas tracejadas são prompts prontos: copie e cole no Claude, trocando o que está entre colchetes [assim].
Dica

Leia um capítulo, faça o vídeo e só então avance. Na primeira vez o processo leva algumas horas; a partir do terceiro vídeo, um formato já montado costuma sair em menos de uma hora, a maior parte esperando a renderização.

Uma palavra sobre "IA que faz tudo"

A IA acelera muito, mas não substitui o seu olhar. Os melhores resultados vêm de quem confere cada rascunho (enquadramento, fatos, piada, ritmo) e pede ajustes. Este curso ensina justamente esse ciclo.

1.1 Como a mágica funciona

Um vídeo animado tradicional é feito em programas de animação, quadro a quadro. Aqui fazemos diferente: o vídeo é escrito como código. Cada cena é uma pequena "receita" que diz onde está cada personagem, cor, texto e movimento em cada instante. Como é código, a IA consegue escrever, e um programa chamado Remotion transforma essa receita em vídeo.

Vocêpede a ideia em português
→
Claudeescreve o roteiro e confere os fatos
→
Voza narração vira áudio com tempo de cada palavra
→
Claudeescreve as cenas animadas no tempo da fala
→
Remotionrenderiza o MP4 9:16
→
Vocêconfere, aprova e posta

O grande truque é a sincronia: quando a narração é gerada, guardamos o instante exato de cada palavra. As cenas usam esses instantes, então quando o narrador diz "BOOM!" a explosão acontece exatamente ali, e a legenda acende palavra por palavra.

1.3 Quanto custa

Resumo honesto dos custos
  • Obrigatório: uma assinatura do Claude que inclua o Claude Code (planos Pro ou Max). O Pro é suficiente para começar.
  • Opcional: ElevenLabs para vozes premium. É cobrado por caracteres de texto narrado; um vídeo de 60 s usa algo entre 600 e 900 caracteres.
  • Zero custo: formatos sem narração (desafio do pause, quiz só com texto, texto cinético com música) e rascunhos com voz grátis.

Preços mudam: confira sempre nos sites oficiais antes de assinar.

Regra de ouro para não desperdiçar dinheiro: todo vídeo nasce com voz grátis. Você assiste o rascunho, pede todas as mudanças de texto e imagem e só então gera a voz paga, uma única vez. Ajustes depois disso (velocidade de um trecho, volume, pausas) são feitos localmente, sem pagar de novo. Vamos configurar o estúdio para seguir essa regra sozinho.

1.4 Do que você precisa

📱 Caminho A: só o celular

  • Celular Android ou iPhone com o app do Claude.
  • Assinatura do Claude com Claude Code.
  • Conta gratuita no GitHub (onde o seu estúdio fica guardado).
  • Internet (Wi-Fi ou 4G).

Nada é instalado no celular: o "computador" é virtual, na nuvem.

💻 Caminho B: no computador

  • Windows 10/11, macOS ou Linux.
  • 8 GB de RAM (16 GB deixa a renderização mais rápida).
  • Uns 10 GB livres no disco.
  • Internet.

Bom para quem quer ver os arquivos e usar o Remotion Studio na tela grande.

Os dois caminhos usam os mesmos prompts

A partir do Módulo 3, tudo é igual: você conversa com o Claude e ele faz o trabalho. A única diferença é onde o trabalho acontece (no seu computador ou num computador na nuvem). Dá até para misturar: começar no celular e abrir o mesmo projeto no computador depois.

Placa de vídeo não é obrigatória

Mesmo os vídeos em 3D deste curso rodam sem placa de vídeo dedicada (o Remotion consegue desenhar o 3D pelo processador). Só fica mais lento: um vídeo 3D de 60 s pode levar de 10 a 30 minutos para renderizar, no computador ou na nuvem.

Caminho A · Só com o celular 📱

É o caminho mais simples: não há nada para instalar. O Claude Code roda num computador virtual na nuvem ligado a um repositório seu no GitHub, e você comanda tudo pelo app do Claude.

  1. Assine o Claude (Pro ou Max) no app ou em claude.ai.
  2. Crie uma conta no GitHub pelo navegador do celular (github.com). Toque em New repository, dê um nome (ex.: meu-estudio), marque Private e Add a README (para ele não nascer vazio) e crie.
  3. No app do Claude, abra a área Code (também dá pelo navegador em claude.ai/code). Na primeira vez ele pede para conectar o GitHub: autorize o acesso ao repositório que você criou.
  4. Escolha o repositório e o ambiente (o computador na nuvem). Na primeira vez, o ambiente padrão serve.
  5. Mande o prompt "CRIAR O ESTÚDIO" do Módulo 3. O Claude instala Node, Remotion, Python e FFmpeg nesse computador na nuvem, monta o projeto e renderiza o teste.
  6. O vídeo chega como arquivo na conversa: toque para assistir em tela cheia, baixe e poste.
Hábitos de quem trabalha pelo celular
  • O computador na nuvem é temporário: o que fica para sempre é o que está no GitHub. Diga no seu CLAUDE.md: "faça commit e push depois de cada vídeo".
  • Renderizações demoram: você pode sair do app e bloquear o celular, o trabalho continua na nuvem.
  • Assista sempre o vídeo em tela cheia antes de aprovar; é assim que o público vai ver.
  • Para continuar um projeto, abra uma sessão nova no mesmo repositório: o Claude lê o CLAUDE.md e as skills e segue de onde parou.
Chave do ElevenLabs no celular

Nunca cole a chave na conversa. Ela é cadastrada nas configurações do ambiente (menu do ambiente → Editar), como segredo de rede para o endereço api.elevenlabs.io; em geral o próprio Claude abre um formulário seguro pedindo a chave quando precisar. Se o ambiente bloquear a internet para esse endereço, o Claude também pede a liberação, e você aprova na tela.

Caminho B · No computador 💻

Siga os passos abaixo uma única vez.

B.1 Conta no Claude

  1. Acesse claude.ai e crie sua conta (e-mail ou Google).
  2. Assine um plano que inclua o Claude Code (Pro ou Max). Você vai usar o mesmo login no terminal.

B.2 Node.js, Git, Python e FFmpeg

Windows

  1. Node.js: baixe a versão LTS em nodejs.org e instale clicando em "Avançar".
  2. Git: baixe em git-scm.com e instale com as opções padrão (ele também instala o "Git Bash").
  3. Python 3: baixe em python.org. Na primeira tela, marque "Add Python to PATH".
  4. FFmpeg: abra o PowerShell e rode winget install ffmpeg.

macOS

Instale o Homebrew (instruções em brew.sh) e depois rode no Terminal:

brew install node git python ffmpeg

Linux (Ubuntu/Debian)

sudo apt update && sudo apt install -y nodejs npm git python3 python3-pip ffmpeg

Conferindo

Feche e abra o terminal de novo, depois rode cada linha. Todas precisam responder com um número de versão:

node -v
git --version
python3 --version   # no Windows: python --version
ffmpeg -version
Apareceu "comando não encontrado"?

Quase sempre é porque o terminal foi aberto antes da instalação. Feche todas as janelas do terminal e abra de novo. Se persistir, reinicie o computador.

B.3 Instalando o Claude Code

O Claude Code é a IA "de mangas arregaçadas": em vez de só conversar, ela mexe nos arquivos do seu projeto. A forma de instalar pode mudar com o tempo, então confira a página oficial (docs.claude.com, seção Claude Code). No momento em que esta apostila foi escrita, os comandos eram:

# macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

# alternativa em qualquer sistema (precisa do Node.js)
npm install -g @anthropic-ai/claude-code

Depois, rode claude no terminal. Na primeira vez ele abre o navegador para você fazer login com a sua conta do Claude.

Prefere uma janela bonita em vez do terminal?

O Claude Code também existe como extensão do VS Code e como aplicativo de computador. Funciona do mesmo jeito; use o que for mais confortável. Nesta apostila mostramos o terminal porque é igual em todos os sistemas.

B.4 Primeiro teste

  1. Crie uma pasta para o estúdio, por exemplo Documentos/estudio.
  2. Abra o terminal dentro dessa pasta (no Windows: clique com o botão direito na pasta → "Abrir no Terminal").
  3. Digite claude e aperte Enter.
  4. Escreva: "Olá! Confere se Node, Python, Git e FFmpeg estão instalados e me diz as versões."

O Claude vai pedir permissão para rodar comandos. Leia o que ele quer fazer e aprove. Se algo estiver faltando, ele explica como instalar.

Permissões

Por segurança, o Claude Code pergunta antes de rodar comandos ou mexer em arquivos. No começo, aprove um por um e leia o que está sendo feito: é a melhor forma de aprender. Depois você pode liberar os comandos que se repetem (ex.: renderizar).
